指定されたZenn記事（Markdownファイル）に対して、以下の3つのフェーズで体系的なレビューを行います。

### 1. Zenn特有のMarkdownチェック
Zennの仕様に基づき、以下の項目をチェックしてください。

- **見出し構造**: `#` (H1) が使用されていないか（記事タイトルとして扱われるため、本文は `##` から開始する必要がある）。
- **コードブロック**: 言語指定（例: `js`, `python`）がされているか。必要に応じてファイル名が指定されているか。
- **画像**: `alt` 属性が設定されているか。
- **独自記法**: `:::message` や `:::details` が効果的に使われているか。
- **数式**: KaTeX記法（`$` または `$$`）が正しく使われているか。

### 2. 石原尚氏の「推敲の3ステップ・9技法」による改善案
以下の3ステップ・9つの技法を順に適用し、具体的な修正案を提示してください。

#### 第1ステップ：構造改良（大工事・工作）
- **切り分ける**: 長い文章を句点で分割し、一文一義（単純な文法）にする。
- **並び替える**: 修飾語と被修飾語など、関連の強い語句を近づけて「楽に読める」状態にする。
- **繋ぎ方を変える**: 文と文の関係（案内板）を正しく理解してもらえるよう接続詞や接続助詞を最適化する。

#### 第2ステップ：整理整頓（片付け）
- **削り落とす**: 意味を変えずに削れる「余談」や「冗長な語句」を削除し、簡潔にする。
- **一貫させる**: パラレリズム（形式の統一）や用語の呼び方を統一し、対応関係を明確にする。
- **まとめる**: 共通語句のくくり出しや熟語への置き換えにより、端的な表現にする。

#### 第3ステップ：意味確定（飾りつけ）
- **明確にする**: 指示代名詞（これ、それ等）の内容を補い、指し示す対象を特定できるようにする。
- **限定する**: 「適切」「様々」などの曖昧な言葉を、数値や専門用語、具体的な基準に書き換える。
- **やさしくする**: 専門外の読者のために、専門用語に平易な解説や言い換えを加える。

参考：https://note.com/hisashi_is/n/n2efd3f4bb09a

---

**実行手順:**
1. 対象の記事ファイルの内容を読み取る。
2. `npm run textlint` を実行し、機械的な修正（多重助詞など）が必要な場合は先に `npm run textlint:fix` を検討する。
3. 石原尚氏の「3ステップ・9技法」および「Zenn特有のMarkdownチェック」に基づき、最終的に「linterエラー0件」かつ「論理的で分かりやすい」状態にするための改善案を提示する。
4. 特に大きな改善が見込める箇所については、修正前後の比較（Before/After）を提示する。
